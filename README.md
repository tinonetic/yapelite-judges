# YapElite — Android build for judges (v1.0.6, build 107)

This is the same build as the one now live on Google Play: https://play.google.com/store/apps/details?id=com.yapelite.yap_elite

**Install:** download `YapElite-1.0.6-b107.apk` from this release, allow "Install unknown apps" for your browser, and open it.

**What's in this build:** the RevenueCat paywall (speaker_pro and organizer_pro subscriptions, Featured Boost and Priority RFP purchases), OneSignal notifications, speaker bids on open calls, and background session renewal so you stay signed in.

**Unlock Pro without paying:** sign in, open the Green Room, tap the medal icon (top right) to reach "Upgrade to Pro", scroll to the bottom, and enter `SHIPATON-JUDGE-2026` under "Redeem Code". This grants the Speaker Pro and Organizer Pro entitlements; Speaker Pro lowers the platform fee on bookings, while Organizer Pro has no enforced in-app benefit yet.
